# Family Tree

Local-first family tree editor in a single HTML file. No build, no backend.

- Miro-style canvas: pan, zoom, pinch, keyboard navigation
- Parents, siblings, children, multiple spouses with marriage dates
- Photos with a crop tool, birth surnames, EN / RU / DE
- Saves to a binary `.ftree` file with all images embedded
- PDF export via the print dialog

Open `index.html` in a browser, or use the hosted version on GitHub Pages.
